# YouTube Clone

A responsive YouTube homepage clone built using HTML and CSS.

## 🚀 Features

- YouTube-style header and navigation bar
- Search bar with search and voice search buttons
- Sidebar navigation
- Video thumbnail grid
- Video duration badges
- Channel profile pictures
- Tooltips for header icons
- Responsive CSS Grid layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Google Fonts (Roboto)
